# Joseph Jerome P J — Portfolio

A responsive, static portfolio built with HTML, CSS and JavaScript and deployed to GitHub Pages by GitHub Actions.

## Before publishing
1. Open `index.html`.
2. Replace `your.email@example.com` with your email address.
3. Replace the GitHub and LinkedIn profile links with your real profile URLs.
4. Review the skills, projects, education and training details. Keep only accurate claims; add links to project repositories and certificates you have earned.
5. Optionally add a CV PDF to the repository and link it from the page.

## Deploy with GitHub Actions
1. Create a new GitHub repository, for example `joseph-portfolio`.
2. Upload all files and folders in this project to the repository root. Make sure `.github/workflows/deploy.yml` is included.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **GitHub Actions**.
5. Open the **Actions** tab. The `Deploy portfolio to GitHub Pages` workflow should run after the push. Wait for the green check mark.
6. Open **Settings → Pages** to find the published URL. It will usually look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
7. Each new push to the `main` branch automatically triggers a deployment. You can also run the workflow manually from the Actions tab using **Run workflow**.

## Updating the website
Edit the HTML/CSS/JS locally or in GitHub's web editor, commit the changes to `main`, and check the Actions tab for deployment status.

## Important
This is a static website. Do not put passwords, private keys, or sensitive personal data in the repository. GitHub Pages sites are public unless the repository and account setup support a different arrangement.
